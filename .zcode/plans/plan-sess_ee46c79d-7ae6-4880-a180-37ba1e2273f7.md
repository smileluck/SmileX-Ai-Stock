# 轮动策略分析功能实施计划

## 定稿决策（按推荐，用户未反对）
- **独立新页** `views/ai/rotation-analysis`，挂 AI 目录（菜单 ID 8032，sort=10）
- **双轨制**：左侧「规则计算的轮动指标」（近期轮动/明日候选/高低切换三张表，透明可回验）+ 右侧「AI 轮动策略报告」（复用 analysis 模块异步生成基建，新增 `rotation` 类型）
- **AI 只推演到板块层**（主攻/潜伏/回避 + 确认信号），个股标的由高低切换表「低位启动股」数据名单给出，AI 不点名个股
- **成分股快照范围**：行业全量(~90) + 概念当日涨幅前30，约120板块/日，规避 push2 限流
- **板块历史回填**：新增板块日K回填（近60日，手动触发的后台任务）——`business_board_daily` 无回填机制，轮动指标需要历史纵深

## 一、数据层（stock 模块）

### 1.1 新表 `BusinessBoardStockDaily`（板块成分股日快照）
- 加在 `database/models/business/stock_market.py`，`business/__init__.py` 注册导出
- 字段：`record_date, board_type, board_code, board_name, stock_code, stock_name, price, change_pct, amount(成交额), turnover_rate, gain_5d, gain_10d`（后两个可空：东财字段实测可用直接带，否则读时自累计）
- 唯一键 `(record_date, board_type, board_code, stock_code)`；索引 `(record_date, board_code)`

### 1.2 `board_fetcher.py` 扩展两个抓取函数
- `fetch_board_history_kline(board_code, days)`：push2his 板块日K（`secid=90.{code}&klt=101&fqt=1`），域名探测 push2his/延时源；akshare `stock_board_industry/concept_hist_em` 兜底；返回 `{date, change_pct, turnover, volume, turnover_rate}`
- `fetch_board_constituents(board_type, board_code)`：复用 `_pick_em_clist_url`，clist 按 `fs=b:{code}` 分页拉全成分（pn 递增 pz=100），fields `f12,f14,f2,f3,f6,f8` + `f109,f160`（5/10日涨幅，实现时实测字段号，不通置 None）；沿用 Semaphore(5)+0.1s 间隔模式

### 1.3 新 `services/rotation_service.py`（读时算指标，不入库——沿用连板概率模式）
- `sync_board_stocks(db, concept_top=30)`：从当日 `BusinessBoardDaily` 选板（industry 全量 + concept 涨幅前30）→ 拉成分股 → 每板块先 delete 当日再批量 insert（学 board_service 防同日混杂模式）
- `backfill_history(db, board_type, days=60)`：逐板块拉日K，`ON CONFLICT DO NOTHING` 只补缺失日期（不覆盖已有快照的净流入等字段）；模块级 asyncio.Lock + 后台任务（`_BACKGROUND_TASKS` 强引用模式）防重复执行
- `get_overview(db, board_type, days=10)`：近N日快照 → 每板块算：今日/近3/5/10日累计涨幅、涨幅排名及变化（今日 vs 5日前）、量比（今日成交额/前5日均）、净流入连续为正天数、近3日涨停家数与最高连板（`BusinessLimitUpStock.industry` 按板块名匹配）→ 规则输出 `stage`（启动/发酵/高潮/退潮/蓄势）+ `tomorrow_score`(0-100) + `action`（主攻/潜伏/回避）；所有因子对 None 容错（回填行净流入为空）
- `get_switch_signals(db, board_type, top_n=15)`：当日涨幅榜前 top_n 板块 × 近2日成分股快照；位置分层键 `gain_10d ?? gain_5d ?? change_pct`，板块内前20%=高位组、后20%=低位组；信号判定：高位组均涨幅 − 低位组均涨幅 ≤ −1pp（或高位<0且低位≥1%）→「高低切换」，高位滞涨低位未动→「分歧」，同涨→「共振」；输出每板块 top5 高位滞涨股 + top5 低位启动股
- 新 `schemas/rotation.py`：RotationOverviewItem / RotationSwitchItem / RotationSwitchStockItem / 同步回填结果模型

### 1.4 新 `endpoints/rotation.py`（stock 模块，最终路径 `/admin/stock/rotation/*`，router.py 挂载）
- `GET /overview?board_type=&days=`、`GET /switch?board_type=&top_n=`（权限复用 `stock:board:list`）
- `POST /sync_stocks`、`POST /backfill?days=60`（权限复用 `stock:board:sync`，backfill 后台执行立即返回）

### 1.5 定时任务
- 新 `scheduler/tasks/rotation_sync.py`：`rotation_stock_sync` cron `38 15 * * mon-fri`（board_sync 15:31、limit_up 15:35 之后）→ `sync_board_stocks`；`main.py` tasks import 列表加一行

## 二、AI 分析层（analysis 模块扩展 `rotation` 类型）
- `schemas/analysis.py`：`ANALYSIS_TYPES` 加 `"rotation"`、名称「轮动策略分析」、`VALID_TYPE_SESSIONS["rotation"] = ("close",)`（仅收盘后生成，可手动随时触发）
- `analysis_executor.py`：
  - `_ROTATION_SYSTEM_PROMPT`：JSON 摘要 `{rotation_summary, recent_boards[3-5]{board_name,board_type,stage,change_pct,viewpoint}, tomorrow_boards[3-5]{board_name,board_type,action(主攻/潜伏/回避),confidence(高/中/低),viewpoint}, switch_signals[{board_name,summary}], key_points, tomorrow_outlook{direction:轮动延续/高低切换/热点退潮/新主线酝酿, summary}}` + markdown 结构（近期轮动复盘/资金与涨停梯队/板块内高低切换/明日轮动推演/风险提示）
  - `_ROTATION_TOMORROW_SECTION` 研判框架：候选板块梯队（主攻/潜伏两档）、每档触发条件=竞价可观察信号、概率倾向、作废条件、产业链联动推演（上游已启动→中下游低位补涨）；复用 `include_tomorrow` 开关
  - `_collect_rotation_data(db)`：行业+概念 overview（明日候选分 top15 ∪ 阶段活跃板块）+ 切换信号 + 涨停池情绪 + 近24h资讯（复用 `_collect_recent_news`，LLM 审核失败摘资讯降级重试机制自动复用）
  - `_build_system_prompt` / `_analyze` 加 rotation 分支；与 sector 的分工：sector=当日盘面点评，rotation=跨日轮动规律+阶段定位+明日埋伏+板块内切换
- `analysis_run.py`：`analysis_auto_generate` 改为 `_generate_for_types("close", analysis_types=("market", "sector", "rotation"))`
